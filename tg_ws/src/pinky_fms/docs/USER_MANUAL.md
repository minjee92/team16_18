# Pinky FMS 사용자 매뉴얼

관제 GUI 를 켜는 것부터 각 미션을 끝내고 끄는 것까지의 순서를 정리한다.
설치·빌드·구조는 [README](../README.md), 동작 원리는 [details.md](details.md) 를 본다.

- 대상: Pinky Pro 로봇(amr_01, amr_02 …)을 관제 PC 에서 운용하는 사람
- 전제: 관제 PC 와 로봇이 같은 Wi-Fi 에 있고, 로봇 전원과 배터리가 충분하다(30% 이상 권장)

---

## 1. 관제 프로그램 켜기

| 방법 | 하는 일 |
|---|---|
| **바탕화면 아이콘 "Pinky FMS"** (권장) | 터미널 창이 뜨고 rosbridge · 관제 노드(traffic_core) · 백엔드 · 웹을 띄운 뒤, 준비되면 브라우저로 GUI(http://localhost:8080)를 연다 |
| 터미널 | `~/pinky/src/pinky_fms/scripts/run_real.sh` 실행 후 브라우저에서 http://localhost:8080 |

- 이미 켜져 있으면 아이콘은 GUI 만 다시 연다.
- **GUI 탭은 하나만** 쓴다. 두 탭이 열리면 나중 탭에 경고가 뜨고, 그 탭은 스택을 자동으로 켜지 않는다.
- 관제 프로그램을 끄려면 "Pinky FMS 관제" 터미널 창을 닫거나 Ctrl+C. 로봇은 꺼지지 않는다(로봇은 GUI 의 OFF 로 끈다).
- 로그: `/tmp/fms_real_backend.log`, `_core.log`, `_rosbridge.log`, `_web.log`

## 2. 화면 구성

```
┌──────────────────────────────── 지도 ───────────────────────┐┌──── Active Fleet ─────────┐
│ [지도 선택▼] [맵 업로드] | [자동 배정 주행]   x, y 커서 좌표  ││ GLOBAL E-STOP │RETURN DOCK│REC LOG │
│                                                             ││ Mission [미션 선택 ▼]        │
│   지도 위: 로봇 위치·방향, 목표, 대기 목표                   ││  (Coordinated: 교통 관제 방식,│
│                                                             ││   Start All / Clear Goals)   │
│                                                             ││ ┌ AMR-01 카드 ─────────────┐ │
│                                                             ││ │상태 배지 Dock Log Diag 📷 │ │
│                                                             ││ │배터리 · pose · Ready 항목 │ │
│                                                             ││ │[ON/OFF][Init Pose][Set Goal][Go]│
└─────────────────────────────────────────────────────────────┘└──────────────────────────────┘
```

로봇 카드:

| 요소 | 뜻 |
|---|---|
| 상태 배지 | OFFLINE / STARTING / IDLE(대기) / BUSY(주행 중) |
| 스택 배지 | `NAV2`, `NAV2 · Init Pose`(초기 위치 필요), `LANE` |
| Ready 항목 | Bringup · Nav2/AMCL · 위치추정 · Lane node 등 미션에 필요한 것이 준비됐는지 (✓ 이면 준비됨) |
| Dock | 이 로봇만 도크(마지막 Init Pose 위치)로 복귀 |
| Log | ROS 로그 / 로봇 launch 출력 |
| Diag | 통신 진단 (ping, ROS heartbeat, DDS 방식) |
| 📷 (카메라) | **Live View** 새 창: 지도 위 로봇 이동 + 로봇 시점 주행 영상 (5장 참고) |

## 3. 공통 준비 (모든 미션)

1. **로봇 켜기 — ON**
   - 카드의 **ON** → IP · SSH 사용자(`pinky`) · 비밀번호 입력 → ON.
     "다음부터 비밀번호 없이 접속"을 체크하면 다음부터 비워도 된다.
   - 로봇에서 bringup(모터·라이다·LED·LCD)이 뜨고 상태가 STARTING → IDLE 로 바뀐다.
   - 로봇의 FMS 패키지가 관제 PC 와 다르면 ON 할 때 **자동 배포**(복사+빌드, 1~2분)가 먼저 돈다. 카드 문구로 진행을 알려 준다.
   - 새 로봇은 Active Fleet 의 **로봇 추가**(ID 는 `amr_03` 같은 소문자 namespace).
2. **지도 고르기** — 지도 툴바에서 선택
   - `mission4_3_lanes_1cm`: 차선이 그려진 지도 (기본)
   - `mission4_3_nolanes_1cm`: 같은 공간에서 차선만 지운 지도
   - 다른 지도는 **맵 업로드**(yaml + pgm/png 를 함께 선택). 고른 지도는 로봇에도 자동으로 보내진다.
3. **미션 고르기** — Mission 선택
   - 고르는 순간 켜진 로봇마다 그 미션에 맞는 주행 스택이 켜진다(Nav2 또는 차선 주행).
   - 스택이 뜨면 카드에 `Init Pose` 가 필요하다고 표시된다.
4. **초기 위치 — Init Pose** (로봇마다)
   - 카드의 **Init Pose** → 지도에서 로봇이 실제로 있는 곳을 **클릭한 채 로봇이 보는 방향으로 드래그**.
   - 정확히 찍기 어렵다면 툴바의 **좌표 입력**: 벽까지 거리(cm)와 방향을 넣으면 후보 위치를 지도에 보여 준다.
   - 지도 위 로봇 표시가 실제 위치·방향과 맞고, 카드 Ready 의 위치추정이 ✓ 가 되면 준비 끝.
   - 이 위치가 그 로봇의 **도크**(RETURN DOCK 복귀 지점)가 된다.

> 미션을 바꾸면 로봇의 주행 스택이 바뀌므로 **Init Pose 를 다시** 해야 한다.

## 4. 미션별 진행

### 4.1 Goal Navigation — 로봇 한 대씩 목적지로 (Nav2)

1. 공통 준비(ON → 지도 → 미션 `Goal Navigation` → Init Pose)
2. 카드의 **Set Goal** → 지도에서 목적지를 클릭·드래그(드래그 방향 = 도착 후 바라볼 방향).
   지도를 먼저 찍고 팝업에서 로봇을 골라도 된다. 숫자로 넣으려면 **좌표 입력**.
3. **Go** → 출발. 상태가 BUSY 가 되고, 도착하면 "목표 도착" 알림 후 IDLE.
4. 멈추려면 **Cancel**.

- 툴바의 **자동 배정 주행**: 로봇을 고르지 않고 목적지만 찍으면, 대기(IDLE) 중인 가장 가까운 로봇이 간다.
- 여러 로봇이 동시에 다녀도 교통 관제(충돌·교착 방지)가 항상 적용된다.

### 4.2 Coordinated Fleet Navigation — 여러 대를 동시에 출발 (Nav2 + 교통 관제)

1. 공통 준비(미션 `Coordinated Fleet Navigation`, **모든 로봇** Init Pose)
2. **Traffic Management** 방식 선택 (진행 중인 미션이 없을 때만 바뀐다)

   | 방식 | 동작 |
   |---|---|
   | **Encounter** (기본) | 두 로봇이 실제로 마주쳤을 때 멈추고 우선권·양보를 정한다 |
   | Predictive | 경로와 도착 시각을 예측해 미리 대기·양보 (이전 방식) |
   | Off | 교통 관제 없이 목표만 전달 (시험용) |
3. 로봇마다 **Set Goal** → 카드에 "대기 목표"로 표시된다(아직 출발 안 함).
4. **Start All** → 확인 창에서 출발할 로봇·목표를 확인 → 동시에 출발.
   잘못 찍은 목표는 카드의 Clear, 전체는 **Clear Goals**.
5. 주행 중 마주치면 한 대가 멈추거나 비켜서고(카드에 WAITING / YIELD 표시), 상대가 지나가면 자동으로 다시 간다.

### 4.3 Vision-based Lane Following — 차선 따라 목적지 갔다가 돌아오기 (카메라 + YOLO)

1. 공통 준비(지도 `mission4_3_lanes_1cm`, 미션 `Vision-based Lane Following`, Init Pose).
   카드 Ready 에 **✓ Lane node** 가 떠야 한다(스택을 켠 뒤 수십 초 걸림).
2. **Set Goal** → 목적지를 **차선 위**에 찍는다.
3. **Go** → 차선을 따라 목적지까지 가고, 도착하면 **Go 를 누른 위치로 되돌아온다**.
   끝나면 바로 다음 목적지를 지정할 수 있다.
4. 멈추려면 **Cancel**.

주행 중 자동으로 하는 일:

| 상황 | 로봇 동작 |
|---|---|
| 코너 | 미리 감속(주황 LED) 후 직선에서 다시 정속 |
| 갈림길(cross_lane) | 일시정지 → 나갈 방향이 비었는지 확인 → 진입. 다른 로봇이 먼저 들어와 있으면 대기(먼저 온 로봇 우선) |
| 앞에 사물·로봇 | 일시정지(빨간 LED), 치우면 다시 출발 |
| 두 로봇이 차선에서 마주침 | 관제가 한 대를 비켜서게(양보) 하고 지나간 뒤 원래 경로로 복귀 |
| 차선을 잃음 | 지도 기준으로 차선을 다시 찾음(최대 15초). 못 찾으면 대기하고 알림 → 사람이 확인 |

- 벽 너머에 있는 로봇·사물은 장애물로 보지 않는다(지도 벽 기준).
- 같은 차선 노드·같은 설정이 모든 로봇에 똑같이 적용된다.

## 5. 공통 기능

### RETURN DOCK — 도크(초기 위치)로 복귀
- 상단 **RETURN DOCK**: 켜진 로봇을 **한 대씩 순서대로** 도크로 보낸다(앞 로봇이 끝나야 다음 로봇 출발).
- 카드의 **Dock**: 그 로봇만. 다른 로봇이 도크 중이면 대기열에 들어간다.
- 진행 중인 미션은 취소되고, **Nav2 로** 복귀한다. 차선 주행 중이던 로봇은 잠시 Nav2(차선 지운 지도)로 바꿔 복귀한 뒤 차선 스택으로 되돌아간다.
- 도크는 마지막 Init Pose 위치다. Init Pose 를 한 적이 없으면 복귀하지 않는다.
- 도크 중 멈추려면 **Cancel**(대기열에서도 빠진다).

### GLOBAL E-STOP — 전체 정지
- 모든 로봇의 주행(Nav2 미션, 차선 주행, 도크 대기열)을 즉시 취소하고 멈춘다. 전원은 꺼지지 않는다.
- "E-STOP 확인" 알림이 뜨면 정지가 전달된 것이다. 확인 응답이 없다는 알림이 뜨면 **로봇을 직접 확인**한다.
- 다시 움직이려면 목표를 새로 지정한다.

### REC LOG — 주행 기록
- 시험 시작 전에 **REC LOG** → 기록 시작, 끝나면 다시 눌러 종료.
- 저장 위치: `~/pinky/logs/rec_<날짜_시각>/`

  | 파일 | 내용 |
  |---|---|
  | `issues.log` | 경고 이상 로그 + 실패한 미션 — **분석은 여기부터** |
  | `events.log` | GUI 에서 누른 버튼과 화면 알림 |
  | `missions.log`, `rosout.log` | 미션 상태 변화, 전체 ROS 로그 |
  | `video_<로봇>.mp4` | 로봇 시점 주행 영상 (5 fps) |
  | `launch/` | 로봇 launch 출력 |
  | `summary.txt` | 요약 |
  | `bag/` | rosbag 원본 |
- 문제가 생기면 이 폴더 경로를 그대로 전달하면 된다.

### Live View — 지도 + 주행 영상 창
- 카드의 📷 버튼 → 새 창. 왼쪽은 지도 위 모든 로봇 위치·최근 60초 경로·차선 목적지, 오른쪽은 로봇별 시점 영상과 상태.
- 영상 칸을 누르면 지도에서 그 로봇이 강조된다. 보기 전용이라 로봇에 명령을 보내지 않는다.
- 영상은 미션 스택(Nav2 또는 Lane)이 켜져 있을 때 나온다(320×240, 약 5 fps). 안 나오면 영상 칸에 이유가 표시된다.
- 브라우저가 팝업을 막으면 GUI 안의 작은 영상 창으로 대신 뜬다. 주소창의 팝업 허용을 켜 두면 좋다.

## 6. 로봇 LED

| LED | 상태 |
|---|---|
| 초록 깜빡임 | 주행 중 (복귀 포함) |
| 주황 깜빡임 | 감속 (코너 등) |
| 빨강 고정 | 정지 · 일시정지 · 대기 · 실패 |
| 빨강 빠른 깜빡임 | 충돌 위험(아주 가까운 장애물) |
| 꺼짐 | 미션 없음 · 미션 종료 |

## 7. 끄기

1. 주행 중이면 **Cancel** 또는 **RETURN DOCK** 으로 정리
2. 카드의 **OFF** (로봇의 주행 스택·bringup 종료)
3. REC LOG 를 켰다면 종료
4. "Pinky FMS 관제" 터미널 창 닫기

## 8. 문제가 생겼을 때

| 증상 | 확인·조치 |
|---|---|
| 아이콘을 눌렀는데 GUI 가 안 뜸 | 터미널 창 문구 확인. 60초 넘으면 `/tmp/fms_real_*.log`. 창을 닫고 다시 실행 |
| 화면 상단 ROS 표시가 `ROS Offline`·`Connection Error`(주황) | rosbridge 가 꺼짐 → 관제 창을 닫고 아이콘 다시 실행 |
| ON 이 실패 | Diag 의 ping 확인(로봇 전원·Wi-Fi), IP·비밀번호 확인 |
| 카드가 `NAV2 · Init Pose` 에서 안 넘어감 | Init Pose 를 다시 정확히(방향 포함). 벽에 너무 붙어 있으면 로봇을 벽에서 조금 떼고 다시 |
| Lane node 가 ✓ 가 안 됨 | 30~40초 기다림 → 그래도 안 되면 미션을 다른 것으로 바꿨다가 다시 Lane 선택, 또는 OFF → ON. GUI 탭이 둘 열려 있지 않은지 확인 |
| 로봇이 한쪽에서 계속 기다림(교착) | 카드 상태·알림 확인 → Cancel 후 다시 Go. 반복되면 REC LOG 폴더 전달 |
| 영상이 안 나옴 | 미션 스택이 켜져 있는지, 로봇 패키지가 최신인지(OFF → ON 시 자동 배포) |
| 코드가 바뀌었는데 로봇에 반영 안 됨 | 관제 창 닫고 아이콘 다시 실행 → GUI 에서 로봇 OFF → ON (자동 배포) |
